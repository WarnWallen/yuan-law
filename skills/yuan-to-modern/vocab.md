# 元代音译用字（外来专名音译）

> 本节供 `yuan-translate` 处理外来专名使用。数据来源：①《元史》非汉人姓名表 179 人；②蔡美彪《元代白话碑集录》碑文人名与译词；③亦邻真《元代硬译公牍文体》音译借词。
> 依据标注：[实证]=两语料统计；[文献]=蔡美彪/亦邻真注释考证；[推断]=据蒙语原名复原推断；[存疑]=待考。

## 总原则

- 元代汉译蒙古语人名、官号**"用字不统一，因译者而异"**（亦邻真）；各地碑文白话译文"出自各地的译史"，同一词异写常见：达鲁花赤/荅刺花赤/達魯花赤、怯列麻赤/怯里马赤/乞里觅赤、窝阔台/月阔台/月古歹。[文献]
- 因此音译选字不必唯一，但**必须从下表实证用字中取**，不得生造元代不见的译法。
- 元代译名用字多为中性字，避开明显吉庆或贬损字。[推断]

## 异写容忍对

同一音节的常见异写，可任选其一，不视为错：儿/兒；答/荅/達；刺/剌；怜/辇；恼/脑；古/兀；台/歹；列/里/觅。

## 现代外来专名音译流程（yuan-translate 规则 15 配套）

1. 按音节拆解现代原名（如 Fermat → fer-mat）；
2. 逐音节查上表取元代译字（-r → 儿，mat → 马）；表中无对应音节的，取元代汉语常用同音字（选中性字，避吉庆贬损字）；
3. 拆不出音节的缩写（DNA、LIGO）与纯现代词：保留原文，加"么道"或"名"标记；
4. 示例：费马 → 费儿马（费=fei 同音字，儿=-r，马=mat）；俄罗斯 → 斡罗思（用元代固有译名，勿用"俄罗斯"）。
