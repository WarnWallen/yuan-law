# 元代地名对照表（共享参考）

本文件供 `yuan-translate`（现代地名→元代地名）与 `yuan-to-modern`（元代地名→今地名）两个 Skill 共享引用。

数据源：《元史·地理志》（中华书局点校本 epub）提取的路府级政区 253 条 + 三大涉外地理篇章外国地名 126 条。

置信度：**确定**=学界定点无争议；**较确定**=治所或有徙移；**待考**=无法可靠定点。

**使用注意**：
1. "今地名"对应元代政区的**治所**，非辖区范围；
2. 有同名异地条目（如桂阳路/桂阳州），翻译时须按行省/国家区分；
3. 州县层级（1000+ 条）未收录；《元史》成书仓促，地理志本身有讹误，本表照录未校勘；
4. 表中无对应者：现代小地名按元代音译规则处理（见 vocab"元代音译用字"节）。
