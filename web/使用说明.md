# 元代断案官 · 零环境访问方式

面向**没有任何 AI 环境**的使用者。两种方式任选：

## 方式一：网页（推荐，零安装）

打开网址即可：

**https://kunfeng129-yuan-judge-web.static.hf.space**

1. 首次使用：在页面顶部「API 地址」与「密钥」栏填入服务信息，点「保存」（自动记在浏览器里，之后不用再填）
2. 在底部输入案情（或点示例案情），回车「呈案」，判词实时流出
3. 支持多轮对话（推官会先"问当"补缺，再出判词）

## 方式二：脚本（Windows，零安装）

双击运行 `判案.bat`（使用 Windows 自带的 curl.exe，无需装任何东西），按提示输入案情即可。
若服务器地址或密钥有变，用记事本打开该文件改 `BASE` 与 `KEY` 两行。

macOS / Linux 用户，终端里粘贴：

```bash
BASE="https://1310259357-jv0d7vxz84.ap-beijing.tencentscf.com/v1"
KEY="sk-yuan-judge-2026"
read -p "案情: " Q
curl -s -X POST "$BASE/chat/completions" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d "{\"messages\":[{\"role\":\"user\",\"content\":\"$Q\"}]}"
```

## 服务信息（部署者维护）

- API 地址：`https://1310259357-jv0d7vxz84.ap-beijing.tencentscf.com/v1`
- 密钥：部署者在腾讯云函数环境变量 `CREDENTIAL` 中设置的值
- 后端：腾讯云函数 SCF（OpenAI 兼容协议）
