# 法条库来源与说明

作者：郭侃 耶律楚材二世

本文档说明 `法条库/` 目录内约 3960 条结构化法条的数据来源、加工流程与已知局限。

## 一、数据来源

| 文献 | 底本 | 获取方式 | 处理 |
|---|---|---|---|
| 《元史·刑法志》（卷102–105） | 宋濂《元史》epub 电子书 | 直接解析 | 律条 1071 条 |
| 《元典章》（陈高华、张帆、刘晓、党宝海点校，中华书局、天津古籍出版社，2011） | 四册 PDF（含文字层） | 提取文字层并按坐标重建行序 | 正集刑部 19 卷、户部 13 卷、新集刑部/户部等断例 1384 条 |
| 《通制条格》（方龄贵《通制条格校注》） | 扫描版 PDF（无文字层） | PaddleOCR-VL 1.6 整册 OCR | 22 卷条格 653 条 |
| 《至正条格》 | epub 电子书 | 直接解析 | 条格 214 条、断例 426 条 |

## 二、加工流程

1. **提取**：PDF 文字层提取 / OCR / epub 解析，全部保留原书页码标记
2. **卷目切分**：按页眉"某部卷之几""卷第X"自动切分，正集与新集分开
3. **结构化**：子代理按《结构化规范》（见同目录 `STRUCTURING_SPEC.md`）逐条提炼为统一格式：

```
## 【条目名】
- 出处：《某书·卷·门类》【原书页码】
- 门类：……
- 原文：……（逐字照录，不增删改）
- 白话释义：……（自撰，不抄现代点校本注释）
- 罪名 / 要件 / 刑罚 / 身份与关系 / 加减刑 / 程序与批复
- 存疑：无 ｜ 有：……
```

4. **索引**：`00_罪名索引.md` 由条目汇总而成，36 门类，含口语关键词供检索

## 三、处理原则

- **原文保真**：原文照录不改；发现可疑错字照录并在"存疑"栏标注
- **白话释义自撰**：不转录任何现代点校本的注释文字
- **注文剥离**：《通制条格》为校注本，方龄贵注文一律剥离，只录正文；注文仅作存疑判断参考
- **表格页跳过**：卷首量刑总表文字层散乱，不据以做条目
- **禁止虚构**：所有条目均来自上述底本，无可比附之处一律明说

## 四、已知局限

- 底本为 OCR 或 PDF 文字层，个别文字可能有讹误；每个存疑条目已在"存疑"栏标注（约 1200 条，主要为文字层坏字、人名异文、系年异文；其中少数涉及刑罚数字）
- 个别页（书影页）无文字层，已单独补 OCR 或跳过
- 遮蔽对照测试 5 案全部与底本原判一致；未覆盖全部条目
- 条目中的"比附推演"为演绎内容，非元代真实判决
