# 元代断案智能体（yuan-judge）v1.0

模拟元代路府推官断案的 opencode Skill。输入白话案情，输出**硬译体判词**与**今语释判**（定性 / 援引 / 历代轻重 / 量刑计算 / 程序申覆 / 断狱考量 / 依据性质），判决逐条可溯源至《元史·刑法志》《元典章》《通制条格》《至正条格》。

## 包内内容

- `skills/yuan-judge/` —— 断案 Skill 本体（SKILL.md + 同目录 vocab.md）
- `skills/yuan-translate/`、`skills/yuan-to-modern/` —— 附送的硬译双向翻译 Skill（各含 vocab.md、geo.md）
- `法条库/` —— 结构化法条约 3960 条：
  - `00_罪名索引.md`（36 门类索引，含口语关键词）
  - `刑事/`（元史刑法志 1071 + 断例 1202）
  - `户婚/`（元典章户部 537）
  - `条格/`（至正条格 214 + 通制条格 653）
- `opencode.json.example` —— 配置模板

## 安装（三步）

1. 将 `skills/` 内全部内容复制到 `<你的项目>/.opencode/skills/`（全局安装则放入 `~/.config/opencode/skills/`）
2. 将 `法条库/` 整个文件夹复制到项目根目录
3. 打开（或新建）项目根目录的 `opencode.json`，把 `opencode.json.example` 中的 `references`（law-index）合并进去；若法条库放在其他位置，改 `law-index` 的 path 即可

## 使用

新开会话，说：

- "用元代视角断案：张三夜里偷了邻居一头牛"
- "断案：某人在城中贩卖鸦片牟利"

Skill 会自动：**问当**补缺（白话选项式追问，最多两轮）→ 定性 → 身份矩阵五维核查 → 检索法条 → 拟判（硬译判词 + 今语释判）→ 无正条时比附，元代不存在的罪名走三段式兜底（史实说明 → 比附推演 → 引导转向真实案件）。

## 特性

- 全类型：刑事、户婚、田宅、钱债、职役、课程、禁约
- 可溯源：每条判决注明出处与原文
- 历代轻重：同罪异代判罚一并列出，按犯时定正例
- 身份视角：性别 / 亲属 / 年龄 / 族群 / 良贱五维核查
- 不虚构：比附推演醒目标注，无正条则明说

## 局限

- 面向历史爱好者教学娱乐使用，非学术工具
- 法条库由 OCR 与 PDF 文字层提取而来，个别原文可能含可疑字符（已在各条目"存疑"栏标注），重要引用请复核原书
- 判词中的比附推演为演绎内容，非元代真实判决
